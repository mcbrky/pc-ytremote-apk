🎮 ytremote Pro
A premium YouTube remote control for Windows PC, powered by Android.
ytremote Pro transforms your Android smartphone into a powerful wireless remote control for YouTube running on your Windows PC. Connect both devices over the same Wi-Fi network and enjoy seamless control from your phone.

✨ Features
🎯 Touchpad Control – Navigate your PC cursor with an intuitive touchpad.
🕹️ Circular D-Pad – Precise directional navigation.
🔊 Volume Control – Adjust system volume directly.
⏯️ Media Controls – Control YouTube playback.
🎤 Voice Search – Search YouTube using voice input.
⌨️ Keyboard Support – Type and search remotely.
🖱️ Air Mouse – Gyroscope-based cursor control.
🎨 Premium Themes – Multiple beautiful remote-control themes.
📱 Responsive UI – Optimized for different screen sizes and orientations.
🔐 Secure Connection – Connect using PC IP address, port, and PIN.
📡 Wi-Fi Connectivity – Control your PC wirelessly over your local network.
🖥️ System Requirements

Android smartphone 
Windows PC 
Both devices connected to the same Wi-Fi network
ytremote PC companion server

🚀 Project Goal
To provide a smooth, modern, and convenient way to control YouTube on a Windows PC using an Android smartphone.
